# Rakshit Maheshwari - Developer Portfolio 🚀

A modern, responsive personal developer portfolio built with **React 19**, **Vite**, **Bootstrap 5**, and **CSS3**. Showcases full-stack and frontend projects, technical skills, education, experience, and an interactive contact form.

---

## 🌟 Features

- **Hero Section**: Personal introduction, resume download button, and dynamic call-to-action.
- **About Me**: Brief bio, core values, location, availability, and social links.
- **Education Timeline**: Detailed academic background (BCA, 12th, 10th) with key coursework and percentages.
- **Work & Open Source Experience**: Experience highlights including Social Summer of Code (SSoC).
- **Interactive Skills Matrix**: Grid of 15+ modern web technologies, libraries, and developer tools.
- **Services**: Full Stack Web Development, REST APIs, Dashboards, Landing Pages, etc.
- **Filtered Projects Showcase**:
  - Filter by tech stack (*Full Stack, React.js, Node.js, Tailwind CSS, Bootstrap*).
  - Direct links to GitHub repositories and live deployments.
- **Contact Form**: Direct messaging powered by [Web3Forms API](https://web3forms.com) with real-time submission feedback.
- **Fully Responsive**: Mobile-first design optimized for desktop, tablet, and mobile screens.
